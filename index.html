Begriffe

TetrominoSpielstein aus vier Quadraten. Es gibt sieben Formen: I, O, T, S, Z, J, L.
TierfigurenJede Form ist ein Tier: I Dackel, O Küken, T Schwein, S Frosch, Z Fuchs, J Pinguin, L Panda. Das Gesicht bleibt beim Drehen aufrecht.
GhostHalbtransparente Vorschau, wo der Stein landen würde.
HoldEin Stein kann einmal pro Zug zur Seite gelegt und später eingesetzt werden.
7-BagZufallsverfahren: alle sieben Formen werden gemischt und nacheinander ausgegeben.
Wall KickBeim Drehen an einer Wand wird der Stein leicht versetzt, damit die Drehung gelingt.
Lock DelayKurze Verzögerung (0,5 s), bevor ein gelandeter Stein festgesetzt wird.
GrundstufePer Schieberegler gewählte Fallgeschwindigkeit. Mit aktivem Level-Anstieg kommt pro Level eine Stufe hinzu (max. 20).
PartikeleffektGrafikeffekt aus vielen kleinen Einzelelementen, hier die Wolken beim Auflösen einer Reihe.
Web Audio APIBrowser-Schnittstelle, mit der Töne direkt im Browser erzeugt werden, ohne Audiodateien.
Web-App-ManifestDatei (manifest.webmanifest), die Name, Symbol und Darstellung festlegt, wenn das Spiel als App auf dem Home-Bildschirm liegt.
StandaloneAnzeige als eigenes App-Fenster ohne Safari-Adressleiste.
Safe AreaBildschirmbereich, der nicht von Statusleiste, Kameraaussparung oder Home-Leiste verdeckt wird.
GitHub PagesKostenloser Hosting-Dienst von GitHub, der Dateien eines Repositorys als Webseite veröffentlicht.
ChiptuneMusikstil mit einfachen Wellenformen, typisch für Videospiele der 80er und 90er Jahre.

Quellen

SpiellogikEigene Implementierung, keine externen Bibliotheken. Klassifizierung: Eigenentwicklung.
TierfigurenEigene, im Code gezeichnete Figuren ohne Vorlage. Klassifizierung: Eigenentwicklung.
MusikEigene Komposition im Chiptune-Stil, ohne Vorlage. Klassifizierung: Eigenentwicklung.
SoundeffekteSynthetisch im Browser erzeugt (Web Audio API). Klassifizierung: Eigenentwicklung.
PunktesystemAn gängige Tetris-Regeln angelehnt (100 / 300 / 500 / 800 Punkte × Level). Klassifizierung: Annahme, nicht gegen eine offizielle Spezifikation geprüft.
iPad-AnpassungenMeta-Tags, Safe Areas und Manifest nach allgemeinem Webstandard-Wissen. Klassifizierung: Annahme, nicht gegen die aktuelle Apple-Dokumentation geprüft.
FarbenBlaupalette als Annäherung an das WAGNER-Erscheinungsbild. Klassifizierung: Annahme, exakte CI-Werte offen.
